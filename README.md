# Railway Booking App

## Project Documentation

The Railway Booking App allows users to book train tickets online, check schedules, and manage bookings with ease. This application is designed to provide a seamless experience for users looking to plan their travel within the railway network.

## Features
- User registration and authentication
- Train schedule viewing
- Ticket booking and cancellation
- Booking history management
- User profile management

## Technologies Used
- Frontend: React.js
- Backend: Node.js
- Database: MongoDB

## Setup Instructions

### Prerequisites
- Node.js (v14 or higher)
- MongoDB Atlas or local MongoDB instance

### Installation Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Shebi907/railway-booking-app.git
   cd railway-booking-app
   ```
2. **Install dependencies for the backend:**
   ```bash
   cd server
   npm install
   ```
3. **Install dependencies for the frontend:**
   ```bash
   cd client
   npm install
   ```
4. **Set up environment variables:**
   Create a `.env` file in the server directory and set the necessary configurations (e.g., database URI).
5. **Run the application:**
   - For the backend:
   ```bash
   cd server
   npm start
   ```
   - For the frontend:
   ```bash
   cd client
   npm start
   ```

### Usage
Navigate to `http://localhost:3000` to access the app.
